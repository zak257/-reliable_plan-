# 全年大样本非预见规划：可执行策略证据与风险下界

本接口服务于 Zhongshan 8760 小时、2000 个规划场景及 10000 个独立验证场景。它保留非预见调度、固定初始 SOC、周期库存及逐机 UC，避免直接构造约 4.03 亿变量、1.05 亿二进制变量的联合场景模型。

## 接受和排除来自不同方向的有效证据

给定容量 $n$，首先执行一套事先定义的因果控制器 $\pi$，获得各路径的实际失供量 $Q_s^\pi(n)$。若同一个控制器的 EENS 和 CVaR 同时满足原限值，就构造了联合非预见模型的可行策略，容量可以接受。

如果该控制器未通过，不会据此排除容量。程序另外计算完全预见连续松弛的失供量下界 $L_s(n)$，满足

$$L_s(n)\le Q_s^\rho(n)\qquad\text{对任意可行非预见策略 }\rho.$$

只有松弛损失的 EENS 或 CVaR 下界已经超限，才证明不存在满足要求的非预见策略，并生成原有下闭容量 cut。松弛中自由但周期的初始库存扩大可行域；因此它仍是固定初始库存事故模型的有效下界，不能用于接受判定。

当因果控制器不通过、下界也不超限时，结论为未决。小模型可以回退到原联合场景树求解；大模型明确停止为未决，不把控制器失败冒充整个规划模型不可行，也不把完全预见通过冒充非预见通过。

每个接受点都有合法非预见策略，每条 cut 只排除真实的固定样本不可行容量，因此主问题的成本下界仍覆盖所有固定树内可行策略。若最终上界与该下界满足 1%，可以报告固定样本非预见容量规划的经济 gap；无需声称这个简单控制器在所有策略中最优。若证据不足，接口不承诺一定能完成规划。

## 本次使用的控制器

`causal_cold_reserve_idle_storage_v1` 的规则在规划和验证之前固定：

1. 根据公开的标称负荷和已声明的天气负荷因子确定目标在线台数。在中山参数下为 2 台。
2. 每小时只依据已观测的设备状态处理故障；故障机组强制停机，按固定模块顺序启用可用冷备用。重新启动遵守最小停机时间。
3. 已经在线的机组保持运行直到故障，不主动停机，因此不会绕过最小开机时间。
4. 柴油出力优先覆盖当前负荷，再使用当前可用风光，剩余缺口记为失供。对已声明的整个负荷范围，预先检查在线最低出力可被负荷吸收。
5. 事故策略中电池保持初始库存，不充不放；SOC 初始值 0.8，首尾库存严格相同。电池仍由标称经济主问题使用和规划；没有删除电池设备或物理约束。

这是有意简单、可审计的保守可行策略。它没有利用储能降低事故失供，也不最小化事故燃料消耗；当前经济目标仍是年化资本加标称燃料及启动成本，事故运行费用没有进入目标。返回的事故策略风险可能高于更好的非预见控制器。

该规则对树外历史同样有定义，且不根据验证场景重新训练或调整。事件加速的备用递推只改变计算方式，不允许提前应对未来故障。测试对修改未来故障和负荷后的决策前缀逐项比较，确保没有泄露未来信息。

## 独立验证和输出

最终容量及控制器固定后，使用另一个种子生成 10000 条年度轨迹并执行相同控制器。训练和验证保存相同的 `controller_sha256`；每条路径均审计功率平衡、SOC、周期库存、设备可用性及逐机 UC。逐场景检查点记录控制器指纹、初末库存和审计结果，损失不标为逐路径最优值。

`accident_controller.json` 保存控制器参数；结果中的 `mean_accident_diesel_energy_kwh` 单独记录事故策略柴油用电量，以免将其与标称经济调度混淆。规划样本上的标准误不用于总体可靠性保证；独立等权验证样本提供 EENS 描述性标准误。有限样本通过不等于总体置信认证。

新配置为 `config/zhongshan_nonanticipative_2000.toml`：全年 8760 小时，2000/10000 样本，风光上限各 10 个模块，文献参照故障参数，EENS/CVaR 限值 100/1000 kWh。求解器配置保持每次 3600 秒、经济 gap 1%。

```bash
./run.sh plan \
  --config config/zhongshan_nonanticipative_2000.toml \
  --solver-config config/solver_3600_1pct.toml
```

可选 `--scenarios` 和 `--validation-scenarios` 复用已保存场景。验证样本数量、种子及生成规律必须符合本次配置，并且与规划种子不同。这个运行模式名为 `nonanticipative_certificates`；原 `nonanticipative` 联合构模接口保留用于小模型求解和对照。
