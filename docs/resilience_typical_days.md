## 数据与聚类

默认读取原年度对照的冻结模拟输入 `reports/resilience_joint_comparison_15000s_20260924T013515Z/shared_year.npz`。使用四类负荷、风电/光伏出力系数和气温，共7组24小时曲线；各组按普通日期的标准差缩放。每个月选2或3个原始日作为medoid，最小化标准化曲线的平方距离；当前最多31个候选日，对1～3个medoid穷举组合。

以下日期保留原始数据和独立运行决策：

- 四个72小时事故窗口及每个窗口前后24小时。
- 核心负荷峰值、总负荷峰值、最低气温所在日及相邻日期。
- 风光平均可用系数最低的连续72小时，以及归一化负荷高、风光低的连续72小时，两端各保留24小时。
- 年初3天、年末2天，保留初始启机和终端任务边界。
- `--extra-days` 指定的补充日期及相邻日期，日期从0计数。

当前输入因此保留44个日期，其余321天映射到24或36个典型日；合计68或80套日内决策。medoid直接选取原始曲线，不将曲线平均或另行缩放到匹配年能量。`aggregation.json`记录每天的代表日、权重、保护原因和数据误差，所有天数权重总和为365。

## 时间结构与近似边界

实现共用普通日的日内运行变量，同时保留365天完整逐小时状态及原始动态约束：

- 电池和UPS电量、柴油机温度不合并、不在午夜重置。
- 柴油机请求、准备队列、启停、最小开机时间仍按实际相邻小时约束；同类日共用的决策必须同时满足每次出现时的前序状态。
- 可平移任务按“到达小时与服务延迟”共用策略，但每个原始任务仍有完整的24小时守恒和服务时限约束。
- UPS补电义务仍按原始24小时滚动窗口检查。
- 四个事故窗口的全部原始数据、故障信息约束、窗口前后电量和设备恢复衔接保持不变。
- UPS桥接和功率下限继续由原始全年核心负荷峰值确定。

这是“medoid输入替换＋重复日策略共用”的近似模型。共享策略可能限制调度自由度，输入替换也可能遗漏某些困难运行点；两种影响方向不同。因此压缩模型最优值既不是原始全年问题的有效下界，也不是未经验证的全年可行成本。

当前实现保留每个小时的状态变量，并在构建后删除完全相同的线性约束；没有仅用每日边界变量展开日内状态。变量压缩主要来自日内控制、启停和柔性任务变量的共享。全部轨迹仍有8760个年度时点，不能把68套日内决策说成只计算了68天的时序。

## 年度费用与风险

目标函数沿原始日历逐小时累计，共用变量在目标中的系数自然等于对应的出现次数。窗口期望费用替代对应正常费用，投资只计一次。输入缩短后再把全部成本乘365/K的做法不适用。

窗口外失供按365天日历累加；四个窗口的条件概率分别归一。年度EENS仍为窗口外失供与各窗口期望失供之和；年度CVaR仍使用原模型的保守上界。聚类天数权重不会替代事故分支概率。

## 求解与复核流程

1. 在近似模型上，用保守初始容量和显式运行策略建立通过完整约束审计的热启动。这个阶段的固定运行策略仅用于初始解。
2. 用初始可行费用界限定近似模型的容量搜索范围，放开全部七类容量及运行决策，运行联合MILP。
3. 固定得到的候选容量，将典型日控制展开到原始8760小时；先尝试固定整数控制的连续调度，作为原始全年可行性见证。
4. 放开原始全年运行决策，继续求解固定容量的原始年度模型，并独立检查功率、储能、温度、任务、故障信息和年度费用。
5. 分别报告近似模型gap和固定容量全年调度gap。两者都不是原始全年容量规划的全局最优性证明。

只有通过原始全年审计的容量才标记 `full_year_original_data_validated=true`。固定策略不可行不能据此判定容量不可行；求解超时且无解也不能称为容量不可行。若需要加密代表时段，可以通过`--extra-days`保留复核发现的困难日期重跑；本版没有自动定位不可行原因和自动加密循环。

## 运行

```bash
/home/yzk/cap_plan/venv/bin/python -m scripts.run_resilience_typical_days \
  --output reports/新的试验目录 \
  --per-month 2 3 \
  --planning-seconds 300 --validation-seconds 120 --seed-seconds 120 \
  --threads 8 --mip-gap 0.01
```

这些预算分别作用于每次求解；建模、审计、导出和数值重试另计。输出目录必须为空。文件包含输入指纹、源代码快照、每轮聚类及权重、初始策略、容量搜索、原始全年复核、求解日志和汇总报告。

本轮增加了热方程有效温度界限，防止长年度递推在预处理中形成数值不稳定的无界温度列；不改变原热方程允许的物理轨迹。求解器在预处理阶段超时时，可能已有可行解但尚无有限下界；这时导出的下界/gap为`null`，不丢弃可行解、不虚构最优性差距。
